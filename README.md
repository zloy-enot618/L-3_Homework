# Прилжение с комическими приключениями!  
---
# Тут вы можете:  
- Просмотреть приключения (запланированные и совешённые)
- Найти нужное приключение вписав куда будет оно совершено.
- Получить ответ от поиска

---

# Для тьютора

- Если поиск не удался - программа выведет отрицательный ответ
- Если поиск удался она выведел кол-во совпадений и эти миссии
- Вводить можно для поиска как хочешь: Марс, марс, МАРС, мАрС - программа сама переведет в нижний регистр
- При добавлении новых путешествий direction можно написать хоть МАРС, хоть МаРс (визуально выведет так), но самая программа при сравнивании введенного для поиска сообщения и direction в списке сама переводит все в нижний регистр и сравнивает.
